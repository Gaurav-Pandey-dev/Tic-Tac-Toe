# 🎮 Tic Tac Toe – Android Game

A classic Tic Tac Toe game developed using **Kotlin** and **Android Studio**. This application allows two players to play Tic Tac Toe on a 3×3 grid, taking turns until one player wins or the game ends in a draw.

## ✨ Features

- Two-player gameplay.
- Interactive 3×3 game board.
- Alternating turns between X and O.
- Automatic winner detection.
- Draw detection.
- Restart game functionality.
- Simple and user-friendly interface.

## 🛠️ Technologies Used

- Kotlin
- Android Studio
- XML Layouts

## 🎯 How to Play

1. Start the game.
2. Player X selects an empty cell.
3. Player O selects the next empty cell.
4. Players continue taking turns.
5. The first player to align three symbols horizontally, vertically, or diagonally wins.
6. If all cells are filled without a winner, the game ends in a draw.
7. Restart the game to play again.
